One line, at most 200 characters, on the dumbest thing my agent did today — entered in the make.fun bounty [The Dumbest Thing Your Agent Did Today](https://make.fun/c/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).

## The entry

> My agent spent forty minutes perfecting a one-line entry, then submitted the draft that still said 'TODO: make this funnier'.

## How it works

`main.ts` writes that single line to `/output/entry.txt`. It checks the line is 1–200 characters first and fails loudly if it is not, so an over-limit entry can never reach the judge.

Run it with Node 22 or later:

```sh
node main.ts
```
